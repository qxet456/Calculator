# 🧮 Python CLI Calculator

A simple command-line calculator built with Python.

This project performs basic arithmetic operations while handling user input and common errors such as invalid numbers and division by zero.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* ✅ Validates numeric input
* ⚠️ Handles division by zero
* 💻 Simple command-line interface
* 🐍 Built entirely with Python

## 📋 Requirements

* Python 3.x

No external packages are required.

## 🚀 Getting Started

Clone the repository: 

```bash
git clone <https://github.com/qxet456/Calculator>
```

Move into the project directory:

```bash
cd <~/Projects/Calculator>
```

Run the calculator:

```bash
python calculator.py
```

Depending on your system, you may need to use:

```bash
python3 calculator.py
```

## 🖥️ How It Works

When the program starts, it asks you to enter numbers and choose an arithmetic operation.

Available operations:

```text
======================
--- OPTIONS ---
 ADDITION = +
 SUBTRACTION = -
 MULTIPLICATION = *
 DIVISION = /
====================
```

Enter one of the following operators:

| Operator | Operation      |
| -------- | -------------- |
| `+`      | Addition       |
| `-`      | Subtraction    |
| `*`      | Multiplication |
| `/`      | Division       |

### Example

```text
~ Type a number : 10
~ Type a number : 5

======================
--- OPTIONS ---
 ADDITION = +
 SUBTRACTION = -
 MULTIPLICATION = *
 DIVISION = /
====================

Type your choice : +

Result: 15
```
